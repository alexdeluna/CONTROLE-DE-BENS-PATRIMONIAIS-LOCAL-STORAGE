Importação local de dados

Selecione uma cópia do modelo oficial. O portal validará abas, identificadores, tombamentos e referências antes de gravar os dados exclusivamente neste navegador.

A importação inicial só funciona com a base local vazia. Os dados não são enviados a servidores e não serão compartilhados entre dispositivos.

Limpeza dos dados locais

Remove cadastros principais guardados neste navegador. O histórico local de movimentações e auditoria será preservado. Esta ação afeta somente este dispositivo.
